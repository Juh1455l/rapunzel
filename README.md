# IA pelo Planeta

Site educativo com um fluxograma interativo sobre formas de usar inteligência artificial para apoiar a proteção do meio ambiente, com uma estética submarina e animações inspiradas em tartarugas, golfinhos e peixes.

## Como usar

Abra `index.html` no navegador. Não há dependências de build: o projeto é composto por HTML, CSS e JavaScript puro.

## Seções interativas

- Oceanos vivos: monitoramento da vida marinha, poluição e pesca ilegal.
- Florestas de pé: detecção de desmatamento, incêndios e restauração.
- Energia inteligente: eficiência e integração de fontes renováveis.
- Cidades resilientes: mobilidade, água e adaptação climática.
- Perceber o planeta: uso de dados, sensores e satélites.

## Estilo visual

- Fundo com atmosfera submarina
- Bolhas animadas
- Elementos de vida marinha: tartaruga, golfinho e peixe
- Fluxograma com botões interativos e modal informativo
